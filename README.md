# سامانه پرسش و پاسخ تصویری به زبان فارسی (Persian Visual Question Answering)

این پروژه پیاده‌سازی کامل، کاربردی و آزمون‌پذیر سامانه پرسش و پاسخ از عکس ورودی کاربر بر اساس سند پروپوزال رسمی مرکز رشد زیست‌بوم علم و فناوری فخرا است.

## 🎯 ویژگی‌های کلیدی منطبق با پروپوزال

1. **پشتیبانی کامل از زبان فارسی و چیدمان RTL:**
   - نرمال‌سازی حروف عربی به فارسی (`ي` به `ی`، `ك` به `ک`)، اصلاح نیم‌فاصله‌ها و تبدیل اعداد.
   - دسته‌بندی پرسش‌ها در ۴ سطح پیچیدگی (سطح ۱: تشخیص اشیاء و رنگ، سطح ۲: شمارش، سطح ۳: روابط مکانی و مقایسه، سطح ۴: خواندن متن و استدلال).
2. **پیش‌پردازش و اعتبارسنجی تصویر:**
   - پذیرش فرمت‌های `JPG`، `PNG` و `WEBP`.
   - تغییر اندازه هوشمند با حفظ نسبت تصویر تا حداکثر وضوح استاندارد `۱۰۲۴×۹۸۰` پیکسل جهت پیشگیری از سرریز حافظه.
3. **پاسخ‌دهی ساختاریافته چندوجهی (JSON):**
   - تولید پاسخ شامل سه فیلد کلیدی: `answer` (پاسخ روان به فارسی)، `confidence` (میزان اطمینان: مطمئن/نسبتاً مطمئن/نامطمئن) و `evidence` (شواهد قابل مشاهده در تصویر).
   - مکانیزم صریح بازگرداندن عبارت «قابل تشخیص نیست» در نبود شواهد کافی به جای حدس و توهم مدل.
4. **قابلیت پیگیری و گفت‌وگوی تکمیلی:**
   - امکان ثبت پرسش‌های چندباره بر روی یک تصویر بارگذاری‌شده بدون نیاز به ارسال مجدد فایل تصویر.
   - ذخیره دائمی تاریخچه گفت‌وگوها، زمان پاسخ، و ثبت بازخورد رضایت (Thumbs Up/Down).
5. **معماری ماژولار و تاب‌آور (Fallback Architecture):**
   - قابلیت اتصال آنی به مدل چندوجهی `Qwen2-VL` مستقر روی **Google Colab** از طریق تونل ngrok.
   - دارای موتور دیداری داخلی (مبتنی بر استخراج ویژگی‌های بصری Pillow) جهت تست و اجرای کاملاً مستقل حتی در صورت عدم دسترسی موقت به اینترنت یا Colab.
   - مکانیزم محافظت در برابر کمبود حافظه (OOM Protection): در صورت افت حافظه گرافیکی، سیستم ابعاد تصویر را ۲۵٪ فشرده کرده و استنتاج را مجدداً تکرار می‌نماید.

## 🚀 راهنمای راه‌اندازی و اجرای دمو

### ۱. اجرای هسته هوش مصنوعی در Google Colab (اختیاری جهت فعال‌سازی پردازش سنگین GPU)

1. فایل [`AI/qwen_colab_gateway.ipynb`](file:///D:/project/persian-vqa/AI/qwen_colab_gateway.ipynb) را در [Google Colab](https://colab.research.google.com/) بارگذاری کنید.
2. از منوی **Runtime > Change runtime type** گزینه **T4 GPU** را فعال نمایید.
3. سلول‌ها را به‌ترتیب اجرا کنید. سلول ngrok آدرس عمومی مانند زیر چاپ می‌کند:
   ```
   Public AI_SERVICE_URL: https://xxxx-xx-xx.ngrok-free.app
   ```
4. این آدرس را برای اتصال بک‌اند یادداشت کنید.

> **نکته:** در صورتی که Colab را اجرا نکنید، سامانه به طور خودکار از موتور بصری محلی استفاده می‌کند و تمامی سناریوها و تبادلات رابط کاربری و وب‌سرویس کاملاً کار می‌کنند.

---

### ۲. اجرای بک‌اند (FastAPI)

با فعال‌سازی محیط مجازی موجود در پوشه backend یا با پایتون ۳.۱۰+:

```powershell
# ورود به پوشه بک‌اند
cd backend

# (اختیاری) اتصال به Colab در صورت فعال بودن
$env:AI_SERVICE_URL = "https://xxxx-xx-xx.ngrok-free.app"

# اجرای سرور FastAPI با پایتون venv
.\venv\Scripts\python.exe -m uvicorn app:app --host 0.0.0.0 --port 8080 --reload
```

- **آدرس مستندات Swagger / OpenAPI:** `http://127.0.0.1:8080/docs`
- **آدرس بررسی سلامت:** `http://127.0.0.1:8080/api/health`
- **رابط کاربری:** نسخه ساخته‌شده فرانت‌اند مستقیماً روی `http://127.0.0.1:8080/` نیز در دسترس است!

### ۳. اجرای فرانت‌اند در محیط توسعه (React + Vite)

در یک پنجره ترمینال دیگر:

```powershell
cd frontend
npm run dev
```

رابط کاربری توسعه بر روی آدرس `http://localhost:5173` باز خواهد شد و کلیه درخواست‌های `/api` و `/uploads` به طور خودکار به سرور FastAPI پروکسی می‌شوند.
